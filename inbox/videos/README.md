# Video inbox

Drop large media here on your Mac (inside this repo), then either:

1. **Local Cursor agent:** leave the file here and ask the agent to optimise it, or
2. **Cloud agent:** commit and push the file, then tell the cloud agent it is ready.

Expected filename for the Growth hero:

`Investor_Intro_with_captions.mp4`

The agent will compress it to `public/videos/investor-intro.mp4` and can remove the source from `inbox/` afterwards so the repo stays lean.
