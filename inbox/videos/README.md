# Video inbox

Drop large media here on your Mac (inside this repo), then either:

1. **Local Cursor agent:** leave the file here and ask the agent to optimise it, or
2. **Cloud agent:** commit and push the file, then tell the cloud agent it is ready.

Expected filenames:

| Use | Inbox / source | Optimised output |
|---|---|---|
| Investors / Growth hero | `Investor_Intro_with_captions.mp4` | `public/videos/investor-intro.mp4` |
| Agents hero | Google Drive / agent source | `public/videos/agent-intro.mp4` |

The agent will compress sources into `public/videos/` and can remove inbox originals afterwards so the repo stays lean.
